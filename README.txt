HOME4LETTING - LIGHT MODERN VERSION

This site is intentionally contained in one index.html file.
There are NO remote image dependencies, so the design should not leave large blank image areas if external assets fail.

GitHub Pages:
1. Create a repository.
2. Upload index.html.
3. Settings > Pages > Deploy from branch > main > /(root).
4. Preview the GitHub URL.
5. Only point home4letting.com at GitHub after the design is approved.

Before final launch:
- confirm the public contact email/phone
- add confirmed CMP/redress details
- add privacy/cookie pages if required
